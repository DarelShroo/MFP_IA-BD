# Sistema de Estudio Avanzado - Modelos de Inteligencia Artificial (MIA)

Este es un sistema web interactivo diseñado para el estudio y repaso de la asignatura "Modelos de Inteligencia Artificial".

## 🚀 Características

- **Lectura Interactiva:** Resúmenes estructurados y fáciles de leer de cada módulo (MIA01, MIA02, MIA03).
- **Flashcards:** Tarjetas interactivas para memorizar conceptos clave y definiciones.
- **Quiz de Evaluación:** Cuestionarios de opción múltiple con retroalimentación inmediata.
- **Diseño Premium:** Interfaz moderna (modo oscuro) optimizada para la lectura y concentración.

## 🛠️ Cómo Ejecutar

Para asegurar el correcto funcionamiento de los módulos de JavaScript (ES Modules):

1.  **Recomendado:** Utiliza una extensión como **"Live Server"** en VS Code.
    - Abre el archivo `index.html`.
    - Haz clic derecho y selecciona "Open with Live Server".
2.  **Alternativa (Python):**
    - Abre una terminal en esta carpeta.
    - Ejecuta: `python3 -m http.server`
    - Abre tu navegador en `http://localhost:8000`.

## 📂 Estructura del Proyecto

- `index.html`: Punto de entrada principal.
- `styles/`: Archivos CSS modulares (main, components, animations, utilities).
- `scripts/`: Lógica de la aplicación.
  - `data.js`: Contiene todo el contenido del temario extraído de los resúmenes.
  - `main.js`: Controlador principal de la interfaz y la lógica de estudio.
